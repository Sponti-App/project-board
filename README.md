# Spontapp Coordination

Team-facing Markdown Kanban for the Spontapp final project.

This repo is intentionally small. The main artifacts are:

- `KANBAN.md`
- `DEPLOYMENT.md`
- `PROJECT-BRIEF.md`
- `AGENTS.md`

Private notes, email logs, raw inbox material, decision drafts, and Office artifacts are not stored here.

## Workflow

1. Martin/Codex updates `KANBAN.md` from standup notes, approved email summaries, and project status.
2. Updates stay short and team-safe.
3. Done cards move to the `Done` section with a date and short note.
4. Changes are committed and pushed only when Martin explicitly asks or when a future approved automation is active.
