# AGENTS.md

This repository is the team-facing Markdown Kanban mirror for the Spontapp final project.

## Purpose

- Keep the current project board readable in GitHub.
- Track card status, owner, support, checkpoint, blockers, and done notes.
- Avoid adding another planning surface beyond this Markdown board.

## Hard Rules

- Only publish team-safe project status here.
- Do not add private email addresses.
- Do not add raw inbox content, private Martin/Codex notes, or personal message excerpts.
- Do not copy Office artifacts into this repository.
- Do not treat this repository as the full documentation workspace.
- Do not modify implementation repositories from here.
- Do not commit or push unless Martin explicitly asks.
- When drafting team-facing updates or Slack-ready messages for Martin to send, end the drafted message with the signature: `Codex, Sponti-app Copilot`.

## Source Inputs

Allowed inputs:

- Martin's direct instructions.
- Standup notes summarized by Martin.
- Approved Gmail reply summaries.
- Read-only GitHub observations from implementation repositories.
- Team-approved decisions.

Local-only source material stays in Martin's private planning workspace and should not be copied here unless it has been summarized into team-safe project status.

## Board Rules

- Move cards between sections instead of crossing them out.
- A card is Done only when confirmed by owner, Martin, or accepted project evidence.
- Keep card notes short.
- Use Sprint checkpoints rather than micro-deadlines unless a specific date matters.
- Nil has final technical vote when architecture decisions are split.
